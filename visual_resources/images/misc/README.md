# Miscellaneous card artwork

These are the user's wallpaper and selected reference images. The cards retain
pastel backgrounds and compact HTML link lists. No new page copy is added.

## Assets and credits

- [reading-wallpaper.jpg](reading-wallpaper.jpg): the user's current desktop
  wallpaper, copied unchanged. Resolution: 1920 x 1080.
- [oogway-pixel.jpg](oogway-pixel.jpg): *Oogway* pixel art by **disemq**
  (DeviantArt: disemq21), using the exact preview supplied by the user.
  The artist's signature remains part of the image.
  [Artist credit / original-post reference](https://www.reddit.com/r/AnimatedPixelArt/comments/gbde8x/).
  Resolution: 576 x 324.
- [council-of-elrond-lego.jpg](council-of-elrond-lego.jpg): *The Council of Elrond*
  by **Paul Trach / Disco86**, using the user's selected LEGO reference.
  [Original Flickr page](https://www.flickr.com/photos/disco86/9450718331/),
  [supplied image URL](https://live.staticflickr.com/3817/9450718331_dc00bacf0f_b.jpg).
  The image was retrieved from a cached copy when Flickr's CDN returned HTTP 429.
  Resolution: 1024 x 666.
- [jedi-training-pixel.png](jedi-training-pixel.png): *Star Wars: Episode IV -
  A New Hope* pixel-art tribute by **Gustavo Viselner**. This is the original PNG
  of the training scene from the user's Reddit image reference.
  [Artist's project](https://www.behance.net/gallery/29419279/Star-Wars-Episode-IV-A-New-Hope),
  [original PNG](https://mir-s3-cdn-cf.behance.net/project_modules/hd/82032829419279.57512fdf2dfe4.png).
  Resolution: 940 x 470.

Files preserve their source pixels. CSS controls responsive framing, with crisp
pixel rendering for the wallpaper, Oogway, and Jedi scenes. Rights in the source
artwork and characters remain with their respective creators and owners.
